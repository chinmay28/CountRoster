# CLA signatures

Written by `.github/workflows/cla.yml` (CLA Assistant Lite) when a
contributor accepts [CLA.md](https://github.com/chinmay28/CountRoster/blob/main/CLA.md)
on a pull request. `signatures/cla.json` is the record — don't edit it by
hand, and keep this branch unprotected so the workflow can commit to it.
